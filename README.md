# Technical Writing Portfolio

Technical writing portfolio focused on software and game development documentation.

My background is in game development and game design, where a significant part of my work involved creating and maintaining technical and project documentation for developers, QA engineers, designers, and other team members.

This repository contains sanitized portfolio versions of documentation based on my commercial experience, as well as technical writing practice projects.

- bonus mechanics;
- UI behavior;
- autoplay;
- game history;
- functional requirement IDs;
- flow diagrams;
- open questions.
